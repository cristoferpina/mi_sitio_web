# 🌐 Mi primer sitio web

Una página de presentación para practicar estructura HTML y estilos CSS.

**HTML · CSS · GitHub Pages**

[Explorar código](https://github.com/cristoferpina/mi_sitio_web) · [Reportar un problema](https://github.com/cristoferpina/mi_sitio_web/issues)

## Qué incluye

- Navegación con enlaces de inicio, acerca y contacto.
- Sección de bienvenida con botón de acceso.
- Hoja de estilos independiente y pie de página.

## Ver en tu equipo

```bash
git clone https://github.com/cristoferpina/mi_sitio_web.git
cd mi_sitio_web
```

Abre [index.html](index.html) en tu navegador. Para modificar la presentación, edita [styles.css](styles.css) y recarga la página.
